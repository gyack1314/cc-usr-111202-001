# 随访资料约定

subject_id只在合成研究内标识人；基线lesion_id在该人内唯一，不同人可有同名病灶。mm为直径毫米，null表示本次缺测，不等于0。visit_day为实际检查日，recorded_day为该修订进入资料的研究日；version为同一人同一检查日的正整数修订号，record_id为原始记录ID。非靶状态absent/stable/progression/unknown分别表示全部消失、无明确进展、明确进展和未知；new_lesion为明确新病灶标识。

两种cutoff都是含当日边界的整数。研究日从0起，不使用本机时钟。若同一修订号和业务键有多个不同载荷则冲突，不用record_id排序覆盖。CR/PR的确认必须在首次PD之前完成；一旦完成，其历史最佳确认等级不因后续PD抹除。确认CR的起点是连续CR段首日，与较早PR起点分开记录。subjects是固定分析队列，s2刻意没有随访。

现有工具清点原始版本与靶病灶引用，不选择修订或推导疗效等级。
